# sdobot

## Назначение

Проект состоит из двух скриптов:

1. **`main.py`** подключается к IMAP-почте и каждые 20 секунд проверяет папку `bot`. Он находит новые письма, извлекает тему и адрес отправителя, помечает письма как прочитанные и передаёт данные второму скрипту.
2. **`telegram_sender.py`** принимает данные от `main.py` и отправляет их в Telegram через Bot API.

Оба файла должны находиться в одной директории.

## Требования

- Python 3
- Установленная библиотека `requests`
- Рабочий IMAP-доступ к почтовому серверу
- Telegram-бот и его токен
- `CHAT_ID` пользователя или группы

## Установка

Создайте директорию и поместите в неё два файла:

- `main.py`
- `telegram_sender.py`

## Настройка `telegram_sender.py`

Укажите токен бота и ID чата:

```python
BOT_TOKEN = "твой_токен"
CHAT_ID = "id_чата"
```

**Как получить `CHAT_ID` для личного чата:** можно воспользоваться ботом `@userinfobot`. Например: `123456789`.

**Как получить `CHAT_ID` для группы:**

1. Добавьте своего бота в группу.
2. Отправьте в группу любое сообщение.
3. Откройте в браузере адрес `https://api.telegram.org/bot<токен>/getUpdates`, заменив `<токен>` на токен бота.
4. Найдите в ответе блок с данными чата:

```json
"chat": {
  "id": -123456789,
  "title": "...",
  "type": "group"
}
```

Для группы `CHAT_ID` обычно отрицательный. Например:

```python
CHAT_ID = "-123456789"
```

## Работа `main.py`

Основная логика:

- подключение к IMAP;
- выбор папки `bot`;
- поиск писем `UNSEEN`;
- извлечение темы и адреса отправителя;
- отметка письма как прочитанного;
- передача данных в `telegram_sender.py`.

Период проверки — **20 секунд**.

## Запуск

Обычный запуск:

```bash
python3 main.py
```

Запуск в фоне:

```bash
nohup python3 main.py &
```

## Формат сообщения в Telegram

```text
Новое письмо
От: <адрес>
Тема: <тема>
```

## Что можно менять

Рекомендуется менять только:

- ключевое слово;
- токен бота;
- `CHAT_ID`;
- настройки поиска писем (`UNSEEN`, `ALL` и другие);
- частоту проверки;
- имя IMAP-папки.
