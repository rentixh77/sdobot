# sdobot

## Назначение

Проект состоит из двух скриптов:

1. main.py — подключается к IMAP-почте, каждые 20 секунд проверяет папку bot, находит новые письма, извлекает тему и отправителя, помечает письмо прочитанным и передаёт эти данные во второй скрипт.

2. telegram_sender.py — принимает данные от main.py и отправляет их в Telegram через Bot API.

Оба файла должны лежать в одной директории
---

## Требования

Python 3  
• Установленная библиотека `requests`
• Рабочий IMAP-доступ к почтовому серверу  
• Telegram-бот с токеном  
• CHAT_ID пользователя или группы
---

## Установка

Создать директорию и поместить туда два файла:
main.py
telegram_sender.py
---

## Настройка telegram_sender.py

Заполнить строки:

BOT_TOKEN = "твой_токен"
CHAT_ID   = "id_чата"
Получение CHAT_ID для личного чата – @userinfobot
Пример: Id: 123456789
Получение CHAT_ID для группы
1. Добавить бота в группу
2. Написать любое сообщение в группу
3. Открыть в браузере: https://api.telegram.org/bot<токен>/getUpdates
4. Найти:
"chat": {
    "id": -123456789,
    "title": "...",
    "type": "group"
}
CHAT_ID будет отрицательным:
Пример: CHAT_ID = "-123456789"
---

## Работа main.py

Основная логика:
 • подключение к IMAP
 • выбор папки bot
 • поиск писем UNSEEN
 • для каждого письма:
    • извлечь тему
    • извлечь отправителя
    • пометить как прочитанное
    • передать данные во второй скрипт

Период проверки — 20 секунд.
---

## Запуск

Обычный запуск:
python3 main.py


Фоновый запуск:
nohup python3 main.py &
---

## Формат сообщения, отправляемого в Telegram

Новое письмо
От: <адрес>
Тема: <тема>
---

## Разрешённые изменения

Можно менять только:
 • токен бота
 • CHAT_ID
 • настройки почты (unseen, all, ...)
 • частоту проверки
 • имя IMAP-папки

Остальную логику менять не требуется.
